# Монгольская грамматика — главы и темы

Самостоятельный сайт по книге R. Kullmann, D. Tserenpil, *Mongolian Grammar*, 2008.

Работает поиск по темам. Книга представлена сканами.

- Все 473 страницы более чёткой копии издания сохранены как изображения WebP без потерь, до 3200 пикселей по длинной стороне.
- Поиск охватывает 817 пунктов оглавления, 5 частей книги и 21 тематический фильтр.
- Добавлены русские названия основных тем и поисковые метки; сохранены английские заголовки.
- Старомонгольское письмо читается на сканах. Поиск не ищет слова внутри изображений.
- Можно перейти к печатному номеру страницы, листать, увеличивать и поворачивать скан.
- При выборе части книги или темы предыдущий поисковый запрос очищается.
- Все 39 пунктов раздела «Лексикология» имеют русские названия.
- Страницы 324–327 восстановлены из более чёткой копии. Страницы 389–390 отсутствуют в обеих копиях; просмотрщик сообщает о пропусках.
- Отдельные ошибки распознавания заголовков ещё возможны. Точные формулировки и примеры следует сверять со сканом.

## Размещение на GitHub Pages

Файлы этой папки нужно разместить в корне отдельного репозитория, сохранив папку `scans`.
В настройках репозитория: **Pages → Deploy from a branch → main → / (root) → Save**.
Точный адрес опубликованного сайта появится в разделе Pages.

Файл `.nojekyll` позволяет публиковать готовые статические файлы без обработки Jekyll.
Сайт не требует сборки, сервера приложений или внешней базы данных.

## Перенос и резервная копия

Все ссылки на изображения относительные: `scans/hq-001.webp` … `scans/hq-473.webp`.
В сайте нет зависимости от адресов Tilda. Чтобы перенести его, достаточно скопировать
содержимое этой папки на другой статический хостинг с сохранением структуры.

В Tilda можно встроить опубликованный сайт через iframe. При переезде меняется один
адрес iframe. Если в будущем используется собственный домен, можно сохранить тот же
адрес для посетителей, сменив хостинг в настройках домена.

`MANIFEST.sha256` содержит контрольные суммы всех файлов выпуска, кроме самого списка.
Отдельный исходный PDF не включён в этот выпуск сайта.
